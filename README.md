# 📊 Income & Expense Tracker App

A **simple and powerful budget tracker** built with **Flutter** and **GetX**!  
This app helps you **track your income and expenses** easily, using a clean interface with visual insights through **pie charts** and **total balances**.  
All data is securely stored **locally** using **SQLite** database.

---

## ✨ Features

- 📱 Bottom Navigation Bar to switch between Transaction, Income, and Expense sections.
- 📝 Transaction Form to add:
  - Transaction Name
  - Description
  - Amount
  - Mode (Dropdown)
  - Category with Image (Dropdown)
- ➕ FAB (Floating Action Button) to save transactions categorized as Income or Expense.
- 🔎 Search functionality in Income and Expense sections to quickly find transactions.
- 📈 Pie Chart visualization showing the distribution of income or expenses.
- 💰 Total Income and Total Expense summary indicators.
- 📋 List of All Transactions with detailed information.
- 🗄️ Local Database Storage using Sqflite for offline data saving.
- ⚡ State Management using GetX for efficient UI updates and smooth performance.
- 🧩 Fully Modular using Stateless Components for better scalability.

---

## 🛠️ Tech Stack

- **Flutter** (UI Framework)
- **Dart** (Programming Language)
- **Sqflite** (Database)
- **GetX** (State Management)
- **Charts Flutter** or similar (for Pie Chart)

---

## 🔥 How It Works

1. Add transactions from the **Transaction** tab.
2. Choose Income or Expense, add details, and save.
3. Transactions appear in their respective tabs.
4. Search and visualize transactions with Pie Charts.
5. Data is safely stored using **SQLite** locally.
